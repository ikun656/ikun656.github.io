局域网传文件

两台设备在同一局域网，无需服务器，点对点直接传文件
怎么用： 发送方和接收方都打开本页，选好角色后，互相复制粘贴一次"邀请码 / 应答码"（可借助微信、QQ 等任意方式转发文本），连接建立后即可传文件。全过程不经过任何服务器，文件只在两台设备之间直传。
前提： 双方都能访问本站点（HTTPS），且处于同一局域网或都可被对方网络连通。
我是发送方
选文件，生成邀请码发给对方
我是接收方
粘贴对方邀请码，回传应答码

发送方

1. 选择要发送的文件
2. 生成邀请码，发给接收方
3. 把接收方回传的应答码粘贴到这里

接收方

1. 粘贴发送方给你的邀请码
2. 把应答码发回给发送方
